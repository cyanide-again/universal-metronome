# Universal Metronome

A Python 3.14 script that allows you to generate a metronome using any time signature, any BPM and any metronome sound.

## Time Signatures

A time signature is what defines the rhythm of a part of or the whole song. For example, a song in 4/4, the most basic
and used time signature, would have 4 quarter (4th) notes in a bar. A song in 3/4 would have 3 quarter notes in a bar
and a song in 6/8 would have 6 eighth notes in a bar. Have fun with the tool, use irregular time signatures, use decimals,
make stuff that is humanly impossible to play!

## BPM

Also known as the tempo, it defines how fast the song is. Most pop songs are around 120 BPM, but some genres and songs use
faster and slower BPMs. Often, speedier songs would be more exciting and intense, and slower songs would be more calming
and pleasing to listen to, with exceptions of course. Make it as fast or slow as you want to, but you probably won't be able
to make much with 0.5 BPM.

## Metronome Sound

Put in the file paths to any wav files you want to be the sound of the metronome, or leave it blank for a default triangle wave
metronome sound.

## Usage

Run the script in your terminal followed by the options for the metronome. Run `python metronome.py -h` for help.
